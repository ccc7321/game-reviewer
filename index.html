    Notes files

    To see notes over the video in VLC, keep the .srt in the same folder as the video with the same name, e.g. game.mp4 + game.srt.

    Backup

    Notes live in this browser only. Clearing browser data deletes them, so save a backup after each game.

    ffmpeg commands

    Paste these into Terminal from the folder that holds the video. Install ffmpeg with brew install ffmpeg. Export the .srt first.

    Clips use -c copy, which is instant but starts at the nearest keyframe, so a clip may start up to a couple of seconds early.
